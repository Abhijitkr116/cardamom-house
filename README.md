# ☕ Cardamom House | Brunch & Coffee

A modern, responsive café website inspired by the charm of Lisbon, Portugal. Cardamom House showcases delicious brunch dishes, specialty coffee, seasonal favourites, and daily specials through a warm, elegant user interface.

## ✨ Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Menu:** Browse brunch, sandwiches, drinks, and sides.
- **Search Functionality:** Quickly find menu items.
- **Category Filtering:** Explore dishes by menu category.
- **Dietary Filters:** Filter items based on dietary preferences.
- **Daily Specials:** Highlight the café's featured dish.
- **Popular & Sold-Out Labels:** Clearly identify popular dishes and unavailable items.
- **Light & Dark Mode:** Switch between light and dark themes, with the selected preference saved for future visits.
- **Animated Navigation:** Smooth mobile menu transitions.
- **Accessibility:** Keyboard navigation, visible focus indicators, and reduced-motion support.
- **Modern UI:** Elegant typography, warm colours, and food photography.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Motion
- **Icons:** Remix Icon
- **Data:** Local JSON
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git (optional, for version control)

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd cardamom-house
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment

The application can be deployed on [Vercel](https://vercel.com/).

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Keep the default Next.js build settings unless your project requires changes.
4. Deploy and open the generated URL.
